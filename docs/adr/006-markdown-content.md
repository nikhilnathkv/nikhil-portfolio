# ADR-006 — Markdown for technical content

- **Status:** Accepted
- **Context:** Projects, blog posts, and research contain long-form technical
  writing.
- **Decision:** Author rich technical content in **Markdown**.
- **Rationale:** Developer-friendly, versionable, portable, easy to render and
  migrate, and excellent for technical writing.
- **Consequences:** A Markdown rendering pipeline on the frontend; extensible to
  richer formats later if needed.
